CloudHost — VPS и облачные платформы (AWS, GCP)
Live-сайт: https://qwetxxx2.github.io/vps-cloud-site/

Автор
Саков Даниил Сергеевич, группа ПМо-141

Тема проекта
VPS и облачные платформы (AWS, GCP)

CSS-фреймворк
Chota (v0.8.1) — https://jenil.github.io/chota/

Технологии
HTML5 — семантическая вёрстка (header, nav, main, aside, footer, table, figure, details)
CSS3 — кастомные стили поверх фреймворка, подход Mobile-First(контрольные точки: <768px, ≥768px, ≥992px), тёмная и светлая темы
JavaScript (нативный) — бургер-меню, переключатель темы(localStorage, prefers-color-scheme), подсветка активного пункта меню
Responsive Images — srcset/sizes, элемент picture, формат WebP
Git + GitHub Pages
Запуск
Открыть index.html в браузере или перейти по ссылке на GitHub Pages.Дополнительных зависимостей и сборки не требуется.

Структура проекта
*.html — 10 страниц сайта (главная, VPS, облако, AWS, GCP, сравнение,блог, FAQ, о нас, контакты)
css/chota.min.css — CSS-фреймворк
css/custom.css — кастомные стили (дизайн-токены, сетка, темы)
js/main.js — меню и переключение темы
img/ — оптимизированные изображения (WebP/JPEG)
Реализованные требования
Единый макет: шапка с навигацией, сайдбар (подписка/акции/ссылки), подвал
Бургер-меню на мобильных, 3 контрольные точки адаптивности
Семантические таблицы (тарифы VPS, сравнение платформ)
Видео через iframe (RuTube/YouTube), карта OpenStreetMap
Формы: подписка в сайдбаре, обратная связь на «Контактах»
