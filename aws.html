Amazon Web Services: лидер рынка

Amazon Web Services (AWS) — крупнейшая облачная платформа в мире. Amazon запустил её в 2006 году, и с тех пор AWS вырос в систему из более чем 200 сервисов и 30+ географических регионов.

AWS начинался с трёх простых сервисов — виртуальных серверов, файлового хранилища и очередей сообщений. Сегодня это экосистема, на которой работают Netflix, Airbnb, NASA и миллионы стартапов. По оценкам аналитиков, на AWS приходится около трети всего мирового рынка публичных облаков.

Ключевые сервисы

  • EC2 (Elastic Compute Cloud) — виртуальные серверы с сотнями конфигураций: от крошечных t3.micro до мощных GPU-инстансов для машинного обучения.
  • S3 (Simple Storage Service) — неограниченное объектное хранилище файлов с гарантией сохранности 99,999999999% (одиннадцать девяток).
  • RDS — управляемые базы данных MySQL, PostgreSQL, MariaDB: провайдер сам делает бэкапы, обновления и репликацию.
  • Lambda — бессерверные вычисления: код запускается по событию, а платить нужно только за миллисекунды выполнения.
  • CloudFront — CDN-сеть доставки контента через сотни точек присутствия по всему миру.
